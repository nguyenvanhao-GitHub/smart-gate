# Smart Gate - Frontend Web

Giao diện quản lý Cửa Khẩu Thông Minh (Smart Gate Web Portal).

## 🚀 Công Nghệ
- **Angular 18** (Standalone components, Signals)
- **Angular Material**
- **Apache ECharts**

## ⚙️ Thiết Lập
1. Cài đặt thư viện:
   ```bash
   npm install
   ```
2. Khởi chạy ở môi trường phát triển:
   ```bash
   npm start
   ```
   Ứng dụng mở tại `http://localhost:4200`.
3. Build dự án:
   ```bash
   npm run build
   ```
